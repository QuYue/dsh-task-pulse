# v1 基线 & v2 卡片版规格

本文记录 live-progress 的版本划分，以及 v2（DSH 内卡片）已经定稿的产品逻辑。
v1 = 当前已发布的网页看板版本；v2 = 在 DSH 输入框上方增加原生进度卡片。

## v1（当前版本）

- 文件是唯一事实源：`sessions/<sessionId>/tasks/<taskId>/`（plan + events）
- 项目 = DSH Session；任务 = 一次用户请求；步骤 = 任务拆分
- 网页看板（8770）：会话列表 → 任务列表 → 任务进度表
- 步骤支持：并行、进度百分比、执行者、开始/结束时间（北京时间）、耗时、
  依赖阻塞、备注（`注` 可展开）、可选证据
- 状态词：完成 / 等待 / 进行 / 失败（跳过/已取消为边缘态）
- 步骤 ↔ 事件流双向跳转；任务/项目可删除（项目可选删磁盘数据）
- 长命令/后台任务用 `board.py exec` 自动记账；远程 `ingest` 推送
- 默认不主动为每个任务建看板；用户要求或任务需要时才启用

## v2 目标

**在 DSH 内新增一个原生卡片视图，与网页版并存，不是替代。**

- 位置：composer 输入框上方的 dock（与原生 Todo list 同层）
- 范围：**只显示当前 session**
- 任务：**只显示最近一次用户提问所产生的任务**；不提供任务切换
- 生命周期：
  - 该请求创建任务后出现；
  - 任务完成后保留显示；
  - 下一次用户提问到达时隐藏（与原生 todo 一致）；
  - 新请求若创建新任务则显示新任务，否则保持隐藏。
  - 实现规则：任务的 `startedAt` 早于“最后一条用户消息”则隐藏。
- 内容：**只放任务进度表**
  - 折叠态（第一行）：任务名 + 状态 + **任务级进度条** + 百分比 + `done/total` + 展开按钮
  - 折叠态（第二行起）：**每个进行中的步骤一行**（并行时多行），每行：
    状态小胶囊（与任务进度表一致的「进行」样式）+ 绿色步骤进度条 + 百分比 + 步骤名；
    不显示「正在：」字样；无进行中步骤时显示「等待下一步」
  - 顺序：**40% 在前，2/5 在后**
  - 展开态：步骤行（状态、步骤 ID/规模/标题、执行者、进度、开始/结束时间、耗时）
  - 不显示证据列；备注用 `注` 图标，点击展开
  - 不显示事件流、计划变更、项目列表
  - 展开后步骤超过 10 条时，步骤表在固定高度内滚动（max-height 300px），页面不被拉长
  - `[打开完整看板]` 打开 8770
- 数据：实时读本地 hub（SSE 或短轮询），与网页同源

## 技术路线

- DSH 客户端插件（`dsh.client` bundle），注册到 composer dock 插槽
- 候选插槽：`conversation.composer.dock` / `conversation.input.dock`
- 插件装进 Desktop profile（`~/.dsh/profiles/desktop`），按 DSH 版本维护
- hub 增加只读 CORS（或 Host 代理），供插件读取 `/api/state`
- 不修改 DSH 本体

## 阶段

| 阶段 | 内容 | 验收 |
|---|---|---|
| B0 | 验证 dock 插槽可被第三方插件注册、插件安装路径可行 | 只读结论 + 最小注册 demo |
| B1 | 插件骨架 + 静态卡片（折叠/展开） | 卡片出现在输入框上方，可展开 |
| B2 | 接 hub 实时数据 + “当前请求任务”生命周期 | 任务更新实时反映，下一次提问隐藏 |
| B3 | `注` 展开、打开 8770、折叠状态持久化 | 交互完整 |
| B4 | 安装脚本、版本兼容说明、发布 | 可重复安装 |

## 边界

- 卡片是轻量附加视图，不取代网页看板；
- 不影响原生 Todo dock；两者可同时存在；
- 普通问答/未启用 live-progress 的请求不会出现卡片；
- 插件升级跟随 DSH 客户端 API；升级 DSH 后需回归验证。
